# Tools

Available tools and their usage guidelines.

## File Operations
- `read_file`: Read file contents
- `write_file`: Create or overwrite files
- `edit_file`: Search and replace within files
- `list_dir`: List directory contents

## Shell
- `exec`: Execute shell commands (sandboxed to workspace)

## Communication
- `message`: Send a message to the user

## Web
- `web_search`: Search the web using Brave Search
- `web_fetch`: Fetch and extract content from URLs

## HTTP Client
- `http_client`: Make HTTP requests (GET, POST, PUT, DELETE, etc.)

## Browser
- `browser`: Automate Chrome via CDP (navigate, click, type, screenshot)

## Background Tasks
- `spawn`: Launch a subagent for independent tasks

## Scheduling
- `cron`: Schedule reminders and recurring tasks

## Memory
- `save_memory`: Persist conversation summaries and important facts
